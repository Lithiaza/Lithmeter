LithMeter v1.7.1.31 - ready-to-run build

Keep all files in this folder together and run SoulMeter.exe as Administrator
before starting SoulWorker. No command prompt or separate injector is needed.

This folder includes a clean default option.xml. The application creates
imgui.ini after first launch as a local setting. A clean install starts with
the original solid dark meter, no Options window and no demo data; transparency
can be enabled from Settings.
